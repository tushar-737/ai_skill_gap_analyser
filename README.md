# 🤖 AI Skill Gap Analyzer

An AI-powered career guidance system that analyzes a user's skills, identifies skill gaps, and recommends suitable career paths based on their education, career interests, and skill proficiency.

The project combines **React, FastAPI, MySQL, and AI-based recommendation techniques** to provide personalized career guidance.

---

## 🚀 Features

### 🎓 Education-Based Career Guidance
- Select your education background
- Supports multiple education categories and programs
- Connects education with suitable career domains

### 💼 Career Recommendations
- Browse careers across multiple domains
- Select a target career
- View skills required for each career
- Compare your current skills with career requirements

### 📊 Skill Gap Analysis
- Rate your skills from 0–100
- Compare current skill level with required skill level
- Identify missing and weak skills
- Calculate career compatibility
- Data Science / ML roles show only the **main skills** (Python, SQL, Pandas, NumPy, Machine Learning). Repeated libraries and extra languages such as Java/C++ are hidden.

### 🔎 Searchable Career Selection
- Search careers and domains
- Easier navigation than traditional long dropdowns
- Keyboard-friendly selection
